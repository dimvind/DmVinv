Key Messenger Demo

Это одностраничный HTML-прототип. Он хранит данные в localStorage в браузере. Для настоящего онлайн-мессенджера с разными людьми и реальной безопасностью нужен сервер.

Регистрация

Создаётся 2 ключа: публичный для добавления и секретный для входа.

Вход

Secret key нельзя публиковать. Он нужен только владельцу аккаунта.
